## Deskripsi

Praktikum 2 membahas penggunaan HTML lanjutan untuk membuat halaman web yang memiliki tabel, form, validasi, semantic HTML, dan multimedia.

Pada praktikum ini dibuat beberapa halaman HTML dan sebuah proyek mini biodata mahasiswa.

---

## Materi Praktikum

Materi yang dipelajari dalam Praktikum 2 meliputi:

1. Membuat tabel data mahasiswa.
2. Menggunakan `thead`, `tbody`, dan `tfoot`.
3. Menggunakan `colspan` pada tabel.
4. Membuat form registrasi mahasiswa.
5. Menggunakan radio button dan checkbox.
6. Menggunakan select dan textarea.
7. Membuat validasi form dengan `required`, `min`, `max`, dan `minlength`.
8. Menggunakan semantic HTML.
9. Menambahkan audio dan video.
10. Membuat proyek mini biodata mahasiswa.
